# CHROMA — головоломка с переливанием цветов

Офлайн-игра для Android: переливайте цветную жидкость, пока в каждой бутылочке не останется один цвет.

## [⬇ Скачать CHROMA.apk](https://github.com/ase1i/chroma/releases/latest/download/CHROMA.apk)

Версия 1.1.0 · Android 8.0 и новее · около 70 КБ

## Как установить
1. Откройте ссылку выше на телефоне и скачайте `CHROMA.apk`. Если браузер предупредит о файле, выберите «Всё равно скачать».
2. Откройте скачанный файл. Android попросит разрешить установку из этого источника: нажмите «Настройки», включите разрешение и вернитесь.
3. Нажмите «Установить».
4. Если Google Play Защита предупредит о неизвестном приложении, нажмите «Подробнее», затем «Всё равно установить». Игра не из Play Маркета, поэтому система её не знает.
5. Иконка CHROMA появится среди приложений.

Названия кнопок на разных телефонах немного отличаются.

## Что внутри
- 300 уровней, все открыты сразу — играйте в любом порядке.
- За уровень 1–3 звезды: чем меньше ходов, тем больше звёзд. Звёзды открывают новые оформления в «Коллекции».
- Подсказки и отмена ходов без ограничений.
- Нет рекламы, энергии, покупок и регистрации.
- Интернет не нужен: приложение не запрашивает ни одного разрешения, включая доступ к сети.
- Прогресс хранится на телефоне. Новую версию ставьте поверх старой — прогресс сохранится.
